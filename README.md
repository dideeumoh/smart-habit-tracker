# Smart Habit Tracker (Product Management Case Study)

This repository documents my end-to-end PM case study for a Smart Habit Tracker app.  
I used **Notion** for PRDs & Roadmap, **Balsamiq** for wireframes, and **GitHub** for documentation & portfolio.

### Contents
- `/docs` → Product vision, roadmap, personas, metrics
- `/prds` → Detailed feature specs
- `/wireframes` → Balsamiq-style wireframes
- `/project-management` → Backlog, release notes, retrospectives

### Goal
To practice and showcase product management workflows without writing code.
